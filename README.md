# Smart Canteen

Веб-приложение для лицейской столовой: меню, корзина, предзаказ, электронная очередь, имя ученика и номер заказа, админ-панель и аналитика.

## Запуск

Требуется Node.js 18+.

```bash
npm install
cp .env.example .env
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Подключение Supabase

1. Создайте проект в Supabase.
2. В `Project Settings → API` скопируйте Project URL и anon/public key в `.env`.
3. Откройте SQL Editor и выполните `supabase/schema.sql`.
4. В Supabase Authentication включите Email provider.
5. Для первого администратора зарегистрируйте пользователя, затем выполните SQL из раздела «Назначение администратора» ниже, подставив его UUID.

### Назначение администратора

```sql
update public.profiles
set role = 'admin'
where id = 'UUID_ПОЛЬЗОВАТЕЛЯ';
```

## Демо-режим

Если `.env` не заполнен, приложение запускается с локальными демонстрационными данными.

Тестовые роли:
- Администратор: `admin@smartcanteen.uz` / `admin123`
- Работник столовой: `staff@smartcanteen.uz` / `staff123`
- Ученик: создайте аккаунт через регистрацию. В этом режиме регистрация/вход и заказы сохраняются в браузере, а не в общей базе данных. Это удобно для презентации, но не является настоящей многопользовательской авторизацией.

## Роли

- `student` — меню, оформление заказа, история заказов и получение по имени.
- `staff` — просмотр заказов, поиск по имени и обновление статуса.
- `admin` — все функции staff, меню, аналитика.

Новые пользователи получают роль `student`. Роль staff/admin назначается доверенным администратором через SQL.

## Важно перед реальным запуском

- Включите подтверждение email в Supabase, если это требуется правилами лицея.
- Настройте SMTP и правила восстановления пароля.
- Проверьте RLS-политики и роли на тестовых аккаунтах.
- Не публикуйте `service_role` key во frontend. Используйте только anon key.
- Данные демонстрационного режима хранятся только в текущем браузере.

## Обновлённая логика выдачи
Ученик указывает имя/фамилию и класс при оформлении. Работник столовой ищет заказ в панели по имени, классу или номеру и нажимает «Подтвердить выдачу». -сканер удалён.

## Меню лицейской столовой
Демонстрационное меню перенесено с фотографии: супы, основные блюда и гарниры. Для супов и ош доступны отдельные цены за 0,5 и 1 порцию. Гарниры указаны по цене за 100 г. Цены — в сумах.
